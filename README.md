# Aurora Studio website

Static website for Aurora Studio. No package installation or build command is required. Deploy the repository root (`.`) as the public output directory.

## Site map

- `/` — English home; `/project/`, `/about/`, `/news/`, `/contact/`, `/services/`, `/support/`, `/governance/`, `/talents/` — main pages.
- `/publishing/` — Aurora Publishing project submission and partnership landing page. English source HTML and localized pages generated by `publishing_i18n.py` from `publishing/i18n.json`; configure the Google Form URL in `publishing/form-config.js`, and see `publishing/README.md` for the one-time Google Forms setup.
- `/project/project-numazu/`, `/project/revenant-of-tsushima/`, `/project/railway-depot/`, `/project/aurora-engine/` — project pages.
- `/zh-hant/`, `/zh-hans/`, `/ja/`, `/ko/` — translated core landing pages. The ACG partnerships page also has complete Traditional Chinese, Simplified Chinese and Japanese versions at `/<locale>/acg-partnerships/`. Publishing has complete Traditional Chinese, Simplified Chinese, Japanese and Korean pages. The media room is available in English, Traditional Chinese, Simplified Chinese and Japanese (`/media/`, `/zh-hant/media/`, `/zh-hans/media/`, `/ja/media/`). Other deeper pages remain in English and are labeled EN from localized pages.
- Selected old news slugs have clearly labeled migration summaries; the full archive has not been restored.

`build.py` (including `acg_partnerships_i18n.py` and `publishing_i18n.py`) and `localize.py` generate the checked-in HTML pages. Run `python build.py && python localize.py` from this directory after editing their source copy. Regenerate `sitemap.xml` when routes change.

News indexes are available at `/news/`, `/zh-hant/news/`, `/zh-hans/news/`, `/ja/news/` and `/ko/news/`. The October 22, 2026 Revenant of Tsushima demo announcement is fully translated into all five languages. Older article bodies remain English, with explicit language labels on translated cards. Edit `news/i18n.json` for translations and the `news_updates` entry in `build.py` for the English article. `python news_i18n.py` regenerates only these news pages, localized homepage news links and sitemap entries, using the checked-in English HTML as the layout shell. Both main site generators invoke it automatically. Use `PYTHONUTF8=1` when running the legacy generators on Windows.

Each news page has a self-canonical URL, reciprocal language alternates (including `x-default`), localized social metadata and matching structured data. News indexes use `CollectionPage`/`ItemList`; the announcement uses `NewsArticle` with the original publication date, plus visible development and access information. No special AI-only markup or guaranteed search/AI visibility is claimed. Search Console indexing, search performance and generative AI inclusion settings must be checked separately after deployment.

Only public game screenshots belong in `assets/`. Keep contracts, invoices, settlement spreadsheets and internal test documents outside this repository.

The existing `CNAME` file is controlled separately and is preserved. Review the deployment preview and current DNS, email and subdomain records before routing `aurora-studio.org` or `www.aurora-studio.org` to a new host.


## Careers & Talent Network

`/careers/` and `/zh-hant/careers/` collect expressions of interest for future and project-based publishing roles. These are not funded vacancy listings. Edit `careers_pages.py`, `careers.css` and `careers.js`; both site generators refresh the pages and navigation. Run `python careers_pages.py` to regenerate only this feature.

The application helper prepares a mailto message to `publishing@aurora-studio.org`. Applicants attach their CV and send it in their own email app. There is no upload endpoint, applicant database or automatic submission. A direct email link remains available without JavaScript. Do not publish candidate information, CVs or internal screening statistics in this repository.
