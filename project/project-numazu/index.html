THE PROJECT

Japan, one route at a time.

Project Numazu brings the city’s urban core, bus routes and coastal atmosphere into OMSI 2. The team recreated familiar landmarks, streets and transit details to give players a place that feels grounded in everyday life.

Developed by Aurora Studio with collaborators including Negi-Kyu Workshop. Released March 2026.

CURRENT RELEASE STATUS

Canonical release information.

Project Numazu was released on Steam in March 2026. Aurora Studio develops the project with collaborators including Negi-Kyu Workshop. The Steam store currently lists Aerosoft GmbH as publisher.
